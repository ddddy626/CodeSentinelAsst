# CodeSentinel visual direction

After login, show a quiet code submission home: one large code input, upload action, language selector, and a clear review button. Detect language by default and let the user search the language list to correct it. Keep unsupported languages visible with an honest availability message.

A collapsible left sidebar holds review history and the active project. Opening a review places the saved source on the left and findings, evidence, and suggestions on the right. Keep a restrained light palette, precise line numbers, and visible loading, empty, and error states. On narrow screens, stack the source and report and overlay the sidebar.
